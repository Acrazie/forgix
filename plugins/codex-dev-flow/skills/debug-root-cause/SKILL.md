---
name: debug-root-cause
description: Use when a stable validation or review issue has failed two code corrections.
---

Operate inside BUILD or ASSURE resolution only after same stable Issue survives two code
corrections. Consume issue/occurrence identities, correction history, current
fingerprints, approved contract, and fresh check evidence. Reproduce, gather evidence,
form one hypothesis, and test minimally without expanding approved scope.

Return root-cause link, tested hypothesis, affected evidence invalidation, and proposed
next action. Third correction requires recorded investigation. Exhausted correction
budget, material contract change, or policy contradiction blocks/returns to SHAPE/GATE;
never relabel correctable failure as success or terminal `failed`.

Authority: [BUILD/ASSURE control loops](../../docs/lifecycle-contract.md#control-loops).
