---
name: discover-change
description: Use when dev-flow needs read-only repository discovery before planning a non-trivial change.
---

Operate only in SHAPE and remain read-only. Consume INTAKE request, effective
constraints, confirmed mode/risk, routing decision, workspace identity, and fresh
Context Capsule references. Inspect only repository guidance, manifests, CI, tests,
conventions, dependencies, risks, and current behavior capable of changing contract.

Return artifact-ready specification evidence: relevant surfaces, commands, constraints,
scope/non-goals, candidate acceptance criteria, risks, provenance, freshness inputs, and
material open questions. Mark missing or stale context; never treat it as proof. Stop
when discovery is sufficient for executable planning or when unresolved material
uncertainty requires block. Do not modify files; parent workflow owns artifact and
capsule projection writes.

Authority: [SHAPE phase contract](../../docs/lifecycle-contract.md#shape).
