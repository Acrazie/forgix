---
name: discover-change
description: Use when dev-flow needs read-only repository discovery before planning a non-trivial change.
---

Inspect repository guidance, manifests, CI, tests, conventions, risks, and current behavior. Return scoped, artifact-ready specification evidence: context and outcome, scope and non-goals, constraints and decisions, acceptance criteria, risks, and open questions. Do not modify files; the parent workflow owns artifact writes.
