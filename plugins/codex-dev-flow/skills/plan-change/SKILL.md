---
name: plan-change
description: Use when dev-flow needs an approved, independently verifiable implementation plan.
---

Produce scoped tasks with files, dependencies, verification, rollback, and acceptance criteria. Map every task to at least one acceptance criterion and expose uncovered criteria. Do not embed complete implementations or brittle line references unless indispensable. Do not execute implementation writes before required approval; return the plan to the parent workflow for persistence in the required artifact.
