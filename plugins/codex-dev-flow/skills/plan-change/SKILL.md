name: plan-change
description: Use when dev-flow needs an approved, independently verifiable implementation plan.
---

Operate only in SHAPE and remain read-only. Consume fresh discovery evidence,
constraints, confirmed mode/risk, and current artifact identity. Produce complete
canonical contract projection: objective, scope/non-goals, stable acceptance criteria,
atomic tasks, dependencies, verification, risks, and rollback controls. Map every task
to at least one acceptance criterion and expose uncovered criteria.

Do not embed complete implementations or brittle line references unless indispensable.
Return canonicalizable content and material uncertainties to parent. Parent alone writes
logical artifact; no Standard filename/template is implied. Do not execute repository
writes before current content-bound Approval. Material uncertainty returns to discovery;
material contract change invalidates affected Approval.

Authority: [SHAPE phase contract](../../docs/lifecycle-contract.md#shape) and
[Approval decision](../../docs/adr/0003-bind-approvals-to-canonical-contracts.md).
